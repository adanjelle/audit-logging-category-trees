# Audit Logging, Category Trees, and Safe Migrations

## Overview

This project demonstrates PostgreSQL database administration through
audit logging, hierarchical category modeling, versioned migrations,
and least-privilege database security.

## Lab Objectives

- Track INSERT, UPDATE, and DELETE operations using audit triggers.
- Store old and new row values as JSONB.
- Model hierarchical categories using a self-referencing table.
- Query category hierarchies using recursive CTEs.
- Manage schema changes with Flyway migrations.
- Apply database roles and least-privilege permissions.

## Project Structure

- `sql/` contains SQL scripts for the lab exercises.
- `migrations/` contains versioned Flyway migration files.
